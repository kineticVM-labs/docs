# KineticVM docs

Mintlify site for KineticVM. `docs.json` is at the repository root.

In the Mintlify dashboard, connect `kineticVM-labs/docs` and leave the subdirectory option off.

Local preview:

```bash
npx mint dev
```

The logo files are `logo/light.svg` and `logo/dark.svg`. The default theme is light, and the theme toggle stays on.

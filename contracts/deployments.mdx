## Confirm what you are talking to

```bash
cast call 0xa361931269F7e0b1957175a48669F14735E61EDA \
  "vault()(address)" \
  --rpc-url https://testnet-rpc.monad.xyz

cast call 0x6e46d149b7d3396b42E874765Cf5a1bb26BD5bA5 \
  "registry()(address)" \
  --rpc-url https://testnet-rpc.monad.xyz
```

The first returns the DeviceVault address. The second returns the KineticRegistry address. If either value differs, the config is not pointed at this deployment.

<Warning>
  The source for these addresses is `contracts/src`. Foundry's broadcast file `contracts/broadcast/Deploy.s.sol/10143/run-latest.json` records commit `5a79ff1` for this deployment. These contracts are not audited.
</Warning>
